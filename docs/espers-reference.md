## Key Augments and Abilities

### Hastega Sources (CRITICAL)
**Natural Hastega** (no esper required):
- **Time Battlemage** (learns naturally on license board)

**Esper-unlocked Hastega:**
- **Machinist**: Famfrit unlocks Hastega

**IMPORTANT**:
- White Mage CANNOT get Hastega (common misconception!)
- Knight CANNOT get Hastega
- Black Mage CANNOT get Hastega
- ONLY Time Battlemage and Machinist can cast Hastega!

### Channeling
- **Time Battlemage**: Hashmal unlocks Channeling
- **Red Battlemage**: Zeromus unlocks Channeling

### Swiftness
- **Monk**: Ultima unlocks Swiftness (x2)
- **Foebreaker**: Hashmal unlocks Swiftness, Ultima unlocks Swiftness

### Heavy Armor Access
- **Archer**: Shemhazai unlocks Heavy Armor (Dragon/Magepower/Grand Helm, Dragon/Maximilian/Grand Armor)
- **Red Battlemage**: Exodus unlocks Heavy Armor (Platinum/Giant/Dragon Helm, Platinum/Carabineer/Dragon Armor)
- **Black Mage**: Exodus unlocks Heavy Armor (Platinum Helm, Platinum Armor), Zeromus unlocks Heavy Armor (Giant's Helm, Carabineer Mail)
- **Bushi**: Zodiark unlocks Heavy Armor (Giant/Dragon/Magepower Helm, Carabineer/Dragon/Maximilian Armor)

## Strategic Esper Assignments

### The "Monk Trinity" (Optimal Monk Build)
1. **Ultima** → Swiftness (x2)
2. **Chaos** → Esunaga, Protectga, Shellga, Holy
3. **Zodiark** → Renew

### Knight as Secondary Healer
1. **Mateus** → Curaga, Regen, Cleanse, Esuna
2. **Hashmal** → Curaja, Faith, Bravery, Confuse

### Red Battlemage as Primary Mage
1. **Cuchulainn** → Firaga, Thundaga, Blizzaga, Sleepga (CRITICAL)
2. **Zeromus** → Channeling
3. **Exodus** → Heavy Armor (if paired with light armor class)

### Time Battlemage Support
1. **Adrammelech** → Cura, Raise
2. **Hashmal** → Channeling
3. **Zeromus** → Addle, Shear (breaks)

### Shikari Tank
1. **Cuchulainn** → Protectga, Shellga
2. **Ultima** → Phoenix Lore (x2)
3. **Shemhazai** → Guns (if using Machinist pairing)

## Notes
- Each esper can only be assigned to ONE character
- Esper assignments are permanent (cannot be changed without resetting licenses)
- Plan your entire party's esper allocation before committing
